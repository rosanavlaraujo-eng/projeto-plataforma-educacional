# Backend

Esta pasta será utilizada para desenvolver o servidor e a API da plataforma.

Responsável principal: Kauan.

## Tecnologias previstas
- Node.js
- Express
- Banco de dados a definir

## Funcionalidades
- Cadastro e autenticação de usuários.
- Armazenamento de questões e provas.
- Registro das versões embaralhadas e seus gabaritos.
- Armazenamento de resultados e notas.
- Controle dos planos e limites de utilização.
- Cadastro e disponibilização de anúncios demonstrativos.
- Integração com o frontend e o módulo de correção.

## Observações
O projeto é acadêmico. Os planos não realizarão cobranças reais e os anúncios serão simulados.
